# MVP data decision

For the hackathon MVP, Supabase remains the operational source for the existing weather, place, profile, and observation routes. Neon is now used as the persistent ledger for one-time Base Sepolia ETH onboarding drips.

This keeps the vertical demo reliable while giving the faucet a durable, unique per-account claim record. The observation tables should be migrated to Neon after the hackathon with parity and replay tests; the MVP does not claim that Neon already powers all application data.
